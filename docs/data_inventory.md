
# Data Inventory

## Data Source

- Dataset: dunnhumby - The Complete Journey
- Provider: dunnhumby
- Download source: https://www.kaggle.com/datasets/frtgnn/dunnhumby-the-complete-journey
- Format: CSV
- Number of files: 8

## Dataset Files

| File | Description |
|---|---|
| transaction_data.csv | Household purchasing transactions |
| product.csv | Product attributes and classifications |
| hh_demographic.csv | Household demographic information |
| campaign_desc.csv | Marketing campaign schedules |
| campaign_table.csv | Household campaign assignments |
| coupon.csv | Campaign coupons and associated products |
| coupon_redempt.csv | Household coupon redemption records |
| causal_data.csv | In-store display and weekly mailer promotion records |

## Data Handling

Raw CSV files are stored locally and will not be committed to the GitHub repository.

Dataset schemas, data-quality checks, transformation procedures, and analytical decisions will be documented as the project develops.
